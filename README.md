# دفتر الغاز — abosmra

تطبيق Android عربي لإدارة ديون وتحصيلات موزّع قناني الغاز المتجول.

## الحالة الحالية

الإصدار الحالي **v2.6.0** مبني بـ **Kotlin + Jetpack Compose + Material 3** ويحتوي على 16 شاشة مترابطة، مع قاعدة بيانات محلية **Room + SQLite** مصممة للاستخدام اليومي طويل المدى.

## المزايا المنفذة

- واجهة عربية RTL.
- الأرقام المالية والهواتف بالأرقام الإنجليزية.
- الدينار العراقي **د.ع**.
- إضافة الزبائن وحفظهم في قاعدة بيانات Room + SQLite.
- دين افتتاحي لكل زبون.
- تسجيل بيع بالدين حسب عدد القناني وسعر القنينة أو كمبلغ مباشر.
- تسجيل التحصيل ومنع الدفع فوق الدين الحالي.
- حالة واضحة عند تسديد الحساب بالكامل.
- سجل حركات مع الرصيد بعد العملية.
- كشف حساب قابل للمشاركة عبر WhatsApp.
- تحصيلات اليوم وديون اليوم.
- ترتيب أعلى المديونيات.
- تجميع الزبائن حسب المناطق.
- بحث فوري بالاسم أو الهاتف أو المنطقة.
- Dashboard للتقارير.
- مركز متابعة للحسابات القديمة.
- تصدير البيانات المحلية بصيغة JSON للنسخ الاحتياطي.
- ترحيل تلقائي مرة واحدة من تخزين SharedPreferences/JSON القديم إلى Room عند التحديث.
- فهارس SQLite للاسم والمنطقة والتاريخ ونوع الحركة، مع Foreign Key بين الزبون وحركاته.
- بيانات تجريبية عراقية تظهر في التشغيل الأول.

## البناء

المستودع يحتوي على GitHub Actions workflow يعمل كبوابة الإصدار المستقر: يتحقق من رقم الإصدار، ثم يشغّل اختبارات المحاسبة وBackup وRoom وCompose و`lintRelease`، وبعد نجاحها فقط يبني **Release APK محسّنًا** ويولّد SHA-256 للملف.

يمكن البناء محليًا باستخدام Gradle 9.6 وJDK 17:

```bash
gradle :app:assembleRelease
```

وسيظهر الملف في:

```
app/build/outputs/apk/release/app-release.apk
```

## الإصدار المستقر

النسخة الحالية **v2.6.0** هي الإصدار المستقر بعد المرحلة 17، وتمت ترقيتها من `v2.6.0-rc1` دون تغيير Schema قاعدة البيانات أو إضافة Migration جديدة. بوابة CI تتحقق من الاختبارات و`lintRelease` والبناء وبصمة SHA-256 قبل رفع الـAPK. راجع `docs/RELEASE_2.6.0.md` لملاحظات الإصدار.

> الـAPK الحالي مخصص للتثبيت المباشر وموقّع بمفتاح Debug. النشر على Google Play يتطلب Production Keystore خاصًا وثابتًا.
