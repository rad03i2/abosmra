# دفتر الغاز — abosmra

تطبيق Android عربي لإدارة ديون وتحصيلات موزّع قناني الغاز المتجول.

## الحالة الحالية

الإصدار الحالي **v2.12.0** مبني بـ **Kotlin + Jetpack Compose + Material 3** ويحتوي على 16 شاشة مترابطة، مع قاعدة بيانات محلية **Room + SQLite** مصممة للاستخدام اليومي طويل المدى.

## المزايا المنفذة

- واجهة عربية RTL.
- اختيار الخط العربي من الإعدادات بين Cairo وTajawal وNoto Sans Arabic وNoto Kufi Arabic.
- التحكم بحجم النص من 85% إلى 110% مع حفظ الاختيار وتطبيقه فورًا.
- الأرقام المالية والهواتف بالأرقام الإنجليزية.
- الدينار العراقي **د.ع**.
- إضافة الزبائن وحفظهم في قاعدة بيانات Room + SQLite.
- دين افتتاحي لكل زبون.
- تسجيل بيع بالدين حسب عدد القناني وسعر القنينة أو كمبلغ مباشر.
- تسجيل التحصيل ومنع الدفع فوق الدين الحالي.
- حالة واضحة عند تسديد الحساب بالكامل.
- صوت مالي موحّد لكل عمليات الدين والتحصيل والتسديد الكامل، مع 3 خيارات قابلة للاختيار والمعاينة من الإعدادات: Cash Register وCoin Cascade وPOS Premium.
- إشعار تأكيد للهاتف بعد ثانيتين مع 3 أصوات مستقلة قابلة للاختيار: Cash Ping وSoft Bell وDouble Chime، مع احترام خيار إخفاء المبالغ.
- نافذة نجاح جديدة بدائرة خضراء متحركة تكتمل خلال ثانية وتظهر علامة الصح، مع زر «موافق» واضح.
- حماية ذرّية من تسجيل نفس الدين مرتين خلال 15 ثانية، مع خيار صريح لتجاوز الحماية عند الحاجة.
- تحذير ذكي للمبالغ غير المعتادة اعتمادًا على Median وآخر الديون الحديثة للزبون.
- إدخال مبلغ الدين بالصوت داخل شاشة إضافة الدين، مع دعم الأرقام العربية المنطوقة والرقمية دون حفظ تلقائي.
- أمر صوتي من الشاشة الرئيسية لتجهيز دين أو تحصيل لزبون موجود، مع مربع مراجعة وتعديل قبل الحفظ.
- تنقل أفقي RTL سريع وسلس بين التبويبات الرئيسية دون ابتلاع تمرير القوائم، وزر الرجوع من التبويبات يعيد إلى الرئيسية.
- منع النقرات المتكررة السريعة في التنقل، مع بقاء حماية الحفظ المزدوج داخل منطق البيانات.
- كشف حساب بصورة احترافية مع خط Cairo واتجاه RTL فعلي، يركز على الرصيد الحالي والحركات التي تكوّنه.
- مشاركة كشف الحساب إلى WhatsApp مع محاولة فتح محادثة رقم الزبون المحفوظ مباشرة ودعم fallback.
- شاشة إضافة زبون محسنة مع صورة من الكاميرا أو المعرض فقط، جلب رقم من جهات الاتصال، وبطاقة تأكيد قبل الحفظ.
- صور الزبائن محفوظة خارج Room للحفاظ على Schema قاعدة البيانات وتظهر في ملف الزبون والقوائم والعمليات والتقارير المالية.
- سجل حركات مع الرصيد بعد العملية.
- كشف حساب قابل للمشاركة كصورة عبر WhatsApp أو تطبيق الرسائل SMS/MMS.
- تحصيلات اليوم وديون اليوم.
- ترتيب أعلى المديونيات.
- تجميع الزبائن حسب المناطق.
- بحث فوري بالاسم أو الهاتف أو المنطقة.
- Dashboard للتقارير.
- مركز متابعة للحسابات القديمة.
- تصدير البيانات المحلية بصيغة JSON للنسخ الاحتياطي.
- ترحيل تلقائي مرة واحدة من تخزين SharedPreferences/JSON القديم إلى Room عند التحديث.
- فهارس SQLite للاسم والمنطقة والتاريخ ونوع الحركة، مع Foreign Key بين الزبون وحركاته.
- بيانات تجريبية عراقية تظهر في التشغيل الأول.

## البناء

المستودع يحتوي على GitHub Actions workflow يعمل كبوابة الإصدار المستقر: يتحقق من رقم الإصدار، ثم يشغّل اختبارات المحاسبة وBackup وRoom وCompose و`lintRelease`، وبعد نجاحها فقط يبني **Release APK محسّنًا** ويولّد SHA-256 للملف.

يمكن البناء محليًا باستخدام Gradle 9.6 وJDK 17:

```bash
gradle :app:assembleRelease
```

وسيظهر الملف في:

```
app/build/outputs/apk/release/app-release.apk
```

## الإصدار المستقر

النسخة الحالية **v2.12.0** تضيف نظام Typography قابلًا للتخصيص من داخل إعدادات التطبيق: أربعة خطوط عربية مضمّنة تعمل دون إنترنت، وتحكم بحجم النص من 85% إلى 110%، مع تطبيق فوري وحفظ دائم. أصبح الحجم الافتراضي 90% لتقليل تضخم Cairo، وتستخدم صورة كشف الحساب الخط المختار نفسه. لا يوجد تغيير في Room Schema أو Migration جديدة. راجع `docs/RELEASE_2.12.0.md` لملاحظات الإصدار.

> الـAPK الحالي مخصص للتثبيت المباشر وموقّع بمفتاح Debug. النشر على Google Play يتطلب Production Keystore خاصًا وثابتًا.
