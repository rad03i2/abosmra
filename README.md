# دفتر الغاز — abosmra

تطبيق Android عربي لإدارة ديون وتحصيلات موزّع قناني الغاز المتجول.

## الحالة الحالية

النسخة الأولى مبنية بـ **Kotlin + Jetpack Compose + Material 3** وتحتوي على تدفق كامل من 16 شاشة مترابطة مع بيانات محلية قابلة للحفظ على الجهاز.

### الشاشات

1. الرئيسية
2. جميع الزبائن
3. إضافة زبون
4. ملف الزبون
5. إضافة دين
6. تسجيل تحصيل
7. سجل حركات الزبون
8. كشف الحساب
9. التحصيلات اليومية
10. ديون اليوم
11. أعلى الزبائن مديونية
12. المناطق / الأحياء
13. البحث الذكي والسريع
14. التقارير والإحصائيات
15. التنبيهات والمتابعة
16. الإعدادات والنسخ الاحتياطي

## المزايا المنفذة

- واجهة عربية RTL.
- الأرقام المالية والهواتف بالأرقام الإنجليزية.
- الدينار العراقي **د.ع**.
- إضافة الزبائن وحفظهم محليًا.
- دين افتتاحي لكل زبون.
- تسجيل بيع بالدين حسب عدد القناني وسعر القنينة أو كمبلغ مباشر.
- تسجيل التحصيل ومنع الدفع فوق الدين الحالي.
- حالة واضحة عند تسديد الحساب بالكامل.
- سجل حركات مع الرصيد بعد العملية.
- كشف حساب قابل للمشاركة عبر WhatsApp.
- تحصيلات اليوم وديون اليوم.
- ترتيب أعلى المديونيات.
- تجميع الزبائن حسب المناطق.
- بحث فوري بالاسم أو الهاتف أو المنطقة.
- Dashboard للتقارير.
- مركز متابعة للحسابات القديمة.
- تصدير البيانات المحلية بصيغة JSON.
- بيانات تجريبية عراقية تظهر في التشغيل الأول.

## الهوية

- الاسم: **دفتر الغاز**
- اللون الأساسي: أخضر بترولي.
- لون مساعد: برتقالي طاقة.
- حالات الدين والتحصيل والمسدد لها تمييز بصري واضح.
- تصميم Material 3 بزوايا ناعمة وأزرار كبيرة مناسبة للاستخدام أثناء الجولة.

## التقنية

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- ViewModel + StateFlow
- SharedPreferences + JSON للتخزين المحلي في النسخة الحالية
- Android API 26+
- Compile / Target SDK 37

## البناء

المستودع يحتوي على GitHub Actions workflow يبني Debug APK تلقائيًا عند كل Push إلى `main`.

يمكن البناء محليًا باستخدام Gradle 9.6 وJDK 17:

```bash
gradle :app:assembleDebug
```

وسيظهر الملف في:

```
app/build/outputs/apk/debug/app-debug.apk
```
